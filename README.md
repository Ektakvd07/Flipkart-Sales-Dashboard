# Flipkart-Sales-Dashboard
This repository contains a Power BI Sales Dashboard built to analyze Flipkart e-commerce sales performance.
The dashboard helps uncover insights related to revenue, product categories, customer ratings, order volume, and regional performance, enabling data-driven business decisions.

The project focuses on data visualization, KPI tracking, and exploratory sales analysis using Power BI.



🎯 Objectives:

Monitor overall sales and revenue performance

Identify top-performing products and categories

Analyze order trends across time

Understand customer behavior using ratings and payment modes

Compare city-wise and category-wise sales distribution



🧩 Dashboard Features:

📈 Sales & Revenue KPIs

🛍️ Product & Category Analysis

🌆 City-wise Sales Performance

💳 Payment Mode Distribution




🛠️ Tools & Technologies:

Power BI – Dashboard creation & data modeling

Excel / CSV – Data source

Power Query – Data cleaning & transformation

DAX – Measures & calculated fields



📊 Key KPIs Tracked:

Total Sales Revenue

Total Orders

Total Quantity

Total Customers

Payment wise Sales Distribution

Category-wise Sales Contribution
